# Dhiraj Chaudhary — Portfolio

A responsive personal portfolio with an animated double-door entrance, project filters, research showcase, timeline, and GitHub project links.

## Live site
Once GitHub Pages is enabled: https://dhee-raz.github.io/Dhiraj_portfolio/

## Local preview
Open `index.html` in a browser, or run:

```sh
python3 -m http.server 8000
```

Then visit http://localhost:8000.

## Deploy
1. In the repository, open **Settings → Pages**.
2. Under **Build and deployment**, select **Deploy from a branch**.
3. Choose **main**, **/(root)**, and click **Save**.
4. Wait for GitHub Pages to publish the site.

## Customize
- Edit the `projects` array in `index.html` to add or update projects.
- Update the Research and Journey sections as milestones change.
- Replace the placeholder LinkedIn URL with your actual profile.
- Add an email address and résumé link only when ready to make them public.
- Project statuses are curated manually; they are not inferred from GitHub activity.
- The entrance is shown once per browser tab session and can be skipped.
- The site uses no build step and no API keys.

## Accessibility
Semantic sections, keyboard-accessible buttons, a skip option, reduced-motion support, responsive layouts, and visible focus indicators are included.
